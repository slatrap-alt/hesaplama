# Acanlar Cari Yönetim

Acanlar Mobilya Dekorasyon için tedarikçi cari hesap takibi.

## Özellikler
- Tedarikçi kartları ve aktif/pasif yönetimi
- Borç, alış, ödeme, iade/alacak, açılış bakiyesi ve düzeltme hareketleri
- Güncel bakiye ve aylık grafikler
- Müşteri dosyalarından tedarikçi seçilerek eklenen giderlerin otomatik cari yansıması
- Hesap ekstresi, CSV dışa aktarma ve JSON yedek
- Firebase Authentication ve Firestore eşitlemesi

## Yayın
GitHub Pages kaynağı `Settings → Pages → Build and deployment → Source: GitHub Actions` olarak seçilmelidir.
